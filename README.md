# 매크로 시나리오 시뮬레이터

환율·나스닥·필라델피아 반도체·유가 같은 해외 지표와 외국인 수급·뉴스 분위기가 한국 대형주에 **어느 방향으로 작용하는지** 점수로 계산해 보는 도구입니다. 같은 공식을 **실제 과거 데이터**에 돌려 얼마나 맞았는지도 보여 줍니다.

> 투자 권유가 아닙니다. 점수는 사람이 정한 업종별 가중치로 계산한 참고 지표이며, 검증된 예측 확률이 아닙니다.

AI Studio로 만든 원본("AI 퀀트 및 가중치 예측 플랫폼")을 다시 만든 것입니다. 원본과 무엇이 다른지는 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)를 보세요.

## 실행

```bash
npm install
cp .env.example .env   # 키는 모두 선택 사항
npm run dev            # http://localhost:3000
```

| 명령 | 내용 |
|---|---|
| `npm run dev` | 개발 서버 (Express + Vite 미들웨어, 포트 3000) |
| `npm run build` | 화면 → `dist/`, 서버 → `dist-server/index.js` |
| `npm start` | 빌드 결과 실행 |
| `npm test` | 예측 공식·백테스트 테스트 (네트워크 불필요) |
| `npm run lint` | 타입 검사 |

## 환경 변수 (모두 선택)

| 이름 | 없을 때 |
|---|---|
| `GEMINI_API_KEY` | 해설은 규칙 기반 문장, 시황 브리핑은 "만들 수 없음" 표시 |
| `GEMINI_MODEL` | `gemini-3.5-flash` |
| `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | 뉴스 칸에 "키 없음" 표시 ([네이버 개발자센터](https://developers.naver.com)에서 검색 API 신청) |
| `PORT` | 3000 |

시세는 Yahoo Finance 비공식 API를 씁니다. 키는 필요 없지만 지연·차단될 수 있고, 그럴 때는 화면에 "시세 없음"으로 표시됩니다.

## 기능

- **관심 종목**: 이름 또는 6자리 코드로 검색해 추가. 목록은 브라우저에만 저장(사용자끼리 공유되지 않음). 삭제는 두 번 눌러 확인.
- **시나리오 조절**: 6개 슬라이더. 처음 값은 오늘 실제 지표. 예시 시나리오 4개(기술주 강세, 고환율·외국인 매도, 반도체 호황, 비용 충격).
- **시나리오 결과**: 신호·점수, 요인별 기여(올림/내림), 5거래일 참고선, 해설(AI 또는 규칙 기반), 최근 뉴스, 요약 공유.
- **과거 검증**: 최근 10거래일을 같은 공식으로 계산한 적중률, '매일 상승' 기준과 비교, 신호대로 했을 때와 그냥 보유했을 때 수익률.
- **시황 브리핑**: Gemini가 웹 검색으로 쓴 아침 브리핑과 출처 (4시간 캐시).
- 모바일 하단 탭(종목 / 시나리오 / 결과), 화면 확대 허용, 터치 영역 44px 이상.
