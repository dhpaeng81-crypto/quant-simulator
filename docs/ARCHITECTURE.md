# 구조와 설계

## 왜 정적 사이트 + 정기 수집인가

| 원본 (Express 서버) | 지금 (정적 + GitHub Actions) |
|---|---|
| 방문자마다 Yahoo·네이버·Gemini를 실시간 호출 → 한도 초과, 느림, 차단 위험 | 하루 두 번 한 곳에서만 수집. 방문자는 JSON 파일만 받음 |
| 서버 호스팅 필요 (Cloud Run 등) | GitHub Pages 무료, 서버 없음 |
| API 키가 서버에 상주 | 키는 Actions 비밀값으로만 사용, 사이트에는 없음 |
| 과거 데이터가 없어 백테스트를 난수로 꾸밈 | 2년치 실제 데이터로 학습·검증 |

국내 시세는 장 마감 후에만 확정되고, 이 모델의 입력(미국 장 마감, 전일 수급)은 하루에 한 번 바뀌므로 "실시간" 호출은 얻는 것이 없습니다.

## 파일

```
shared/                 수집기와 화면이 함께 쓰는 코드
  types.ts              JSON 형식
  stats.ts              정규분포, 릿지 회귀, 상관계수
  features.ts           원자료 → 표본(입력 14개, 대상 2개). 미래 정보 누출 방지
  model.ts              릿지·패널 학습, 극단값 자르기, 확률 보정, 워크포워드 평가, 지표
scripts/
  collect.ts            수집 → 학습 → 백테스트 → public/data/
  http.ts               타임아웃·재시도·호출 간격(120ms)
  sources/naver.ts      시가총액 순위, 일봉, 투자자별 매매, 뉴스
  sources/yahoo.ts      해외 지표 일봉
  sources/gemini.ts     (선택) 시장 배경 해설
src/                    React 화면 (정적 JSON만 읽음)
tests/                  모델 테스트 (가짜 시장 데이터로 검증)
.github/workflows/      update.yml(수집·배포), ci.yml(PR 검사)
```

## 데이터 파일

- `data/index.json`: 갱신 시각, 채택 모델과 확률 보정값, 지수·해외 지표, 100개 종목 요약(시가·종가 상승 확률, 적중률), 시장 요약
- `data/stocks/{코드}.json`: 최근 120거래일 원자료, 다음 거래일 입력값과 기준 날짜, 시가·종가 각각의 모델 계수·예측·최근 60일 사후 성적, 뉴스 3건, 재무·투자 지표(현재 값 + 연간 실적)
- `data/evaluation.json`: 모델 3개 × 대상 2개 통합 평가, 보정 구간표

전체 약 2MB. 종목 파일은 선택할 때만 받습니다.

## 모델 (2차)

### 예측 대상 2개
- **시가 갭**: 전일 종가 → 당일 시가. 밤사이 미국 시장이 대부분 반영되는 구간이라 실제 신호가 있습니다.
- **종가**: 전일 종가 → 당일 종가. 갭 + 장중 움직임(대부분 잡음)이라 50% 근처가 정상입니다.

### 입력 14개 (거래일 t 장 시작 전에 알 수 있는 값만)

| 묶음 | 입력 | 정의 |
|---|---|---|
| 밤사이 해외 | 나스닥, 필라델피아 반도체, **EWY**, **VIX**, 원/달러, WTI, **달러지수** | t보다 앞선 마지막 일봉의 변화율(%) |
| | **미국 10년 금리** | 같은 방식, 변화폭(bp) |
| 수급 | 외국인·기관 순매수 1일 | t−1일 순매수량 ÷ 20일 평균 거래량 × 100 |
| | **외국인·기관 순매수 5일** | t−5…t−1 누적 ÷ 20일 평균 거래량 × 100 |
| 종목 흐름 | 전 거래일 수익률, **최근 5일 수익률** | |

굵게 표시한 것이 2차에서 추가한 입력입니다. EWY는 미국에 상장된 한국 주식 ETF로, 우리 장이 닫힌 뒤의 한국 주식 가격 변화를 직접 보여 줍니다.

### 학습
- 릿지 회귀. 입력은 학습 기간 평균 ± 5 표준편차로 **잘라서** 씁니다(극단값에서 선형 모델이 과장하는 문제 방지). 3 표준편차는 실험에서 시가 성적을 떨어뜨렸습니다(큰 갭이 실제로 큰 해외 변동을 따라가기 때문).
- **패널 모델**: 100종목을 합쳐 공통 계수를 구한 뒤(λ = 0.01 × 표본 수), 종목별 차이는 강하게 수축해서(λ = 1 × 종목 표본 수) 더합니다. 종목마다 250일로 따로 학습하는 것보다 표본이 100배라 계수가 안정적입니다.
- 비교 대상 4개를 매번 함께 평가합니다: **1차**(입력 7개, 자르기 없음), **기본**(입력 7개, 5σ 자르기, 사용 중), **확장**(입력 14개), **패널**(입력 14개, 100종목 공통 + 종목별 수축 0.2).

### 확률 보정
z = 기대수익률 ÷ 잔차 표준편차에 p = 1/(1+e^−a·z)를 맞춥니다(기울기 a만). 확신 정도만 바로잡고, 기간마다 달라지는 상승 비율 쏠림(절편 b)은 따라가지 않습니다. 실험에서 b까지 맞추면 시가 성적이 오히려 나빠졌습니다.

## 통합 평가와 모델 선택 (`scripts/collect.ts`)

1. 최근 250거래일을, 5거래일마다 **그 전 250거래일만으로** 다시 학습해 예측합니다(워크포워드). 100종목 × 250일 ≈ 2만 5천 건, 모델 3개 × 대상 2개.
2. 앞 125일 예측으로 확률 보정 a, b를 맞추고, **뒤 125일**에서 성적을 잽니다(보정도 미래를 보지 않음).
3. 지표: 적중률, 확률 점수(Brier skill = 1 − Brier ÷ 기본 비율 Brier), 매일 상위 20%−하위 20% 수익률 차, 보정 구간표.
4. 기본적으로 **기본 모델**을 씁니다. 확장·패널 모델이 종가 확률 오차를 기본 모델보다 **t ≥ 2**로 줄이고(날짜별 묶음 표준오차) 시가에서도 나빠지지 않을 때만 자동으로 바꿉니다. 우연한 차이로 매일 모델이 바뀌지 않게 하려는 규칙입니다. 결과는 `data/evaluation.json`과 화면의 '모델 성적표'에 공개합니다.
5. 실사용 보정은 채택 모델의 250일 사후 예측 전체로 다시 맞추고, 최종 모델은 최근 250거래일로 학습합니다.
6. 종목 화면의 '과거 성적'(최근 60일)은 1의 사후 예측이며, 이 60일은 뒤 절반에 속하므로 앞 절반으로 맞춘 보정을 씁니다.

`REUSE_CACHE=1 npm run collect`로 직전 원자료(`.cache/raw.json`)를 재사용해 평가·학습만 다시 돌릴 수 있습니다.

## 원본에서 고친 문제

| 원본 | 지금 |
|---|---|
| 백테스트 예측이 난수(72% '적중' 고정) | 워크포워드 실제 검증 |
| 사람이 정한 가중치를 "머신러닝"으로 표기 | 실제 데이터로 학습, 계수 공개 |
| 환율·유가 부호가 이중으로 뒤집혀 의도와 반대로 계산 | 회귀가 방향을 데이터에서 추정 |
| 확률 = 35 + 60·sigmoid (점수 0에서 '상승 65%') | Φ(μ/σ), 0이면 50% |
| 외국인 수급을 AI 검색·추정치로 채움 | 네이버 투자자별 매매 실측값 |
| 뉴스 실패 시 가짜 헤드라인 | 없으면 "없음" |
| 종목 목록이 서버 전역 변수(모든 사용자 공유) | 관심 종목은 각자 브라우저에 |
| 날짜 하드코딩(2026-05-30) | 실제 날짜 |
| 확대 금지, 버튼 11.5px | 확대 허용, 본문 14px+, 터치 44px+ |

## 재무·투자 지표

`scripts/sources/naver.ts`의 `fundamentals()`가 종목마다 두 번 요청합니다(`/integration`: PER·PBR·배당·52주 범위·목표가, `/finance/annual`: 연간 실적 3년 + 추정 1년). 배당성향은 주당배당금 ÷ 주당순이익으로 직접 계산합니다(순이익이 0 이하면 없음). 화면에 보여 주기만 하고 **예측 모델의 입력에는 쓰지 않습니다**(분기·연 단위 값이라 하루 방향과 관계가 약하고, 발표 시점 정보가 없어 미래 정보 누출을 막기 어렵기 때문).

## 오늘 예상 가격 범위 (`shared/range.ts`)

- 예상 시가 = 전일 종가 × (1 + 시가 갭 기대 수익률), 범위 ± 갭 모델 잔차 1표준편차
- 하루 범위 = 예상 시가 × (1 ± 최근 20거래일 '시가 대비 고가/저가' 중앙값), 넓은 범위는 80% 분위
- 화면에서 계산하므로 시나리오를 바꾸면 범위도 바뀜. 가격은 호가 단위로 반올림
- 점검(평가 뒤 절반, 약 1만 2천 건): 시가가 예상 범위 안 약 70%, 고가·저가가 보통 범위 안 약 52% / 44%, 넓은 범위 안 약 75% / 70%
- 일봉 시험에서 '시가보다 k% 아래 지정가 매수 → 종가 매도'는 k = 0~3%, 변동폭 기준 모두 비용(왕복 약 0.23%) 차감 후 손실. 그래서 매수 가격 추천은 하지 않음

## 분봉 쌓기 (`scripts/collect-minute.ts`)

- 네이버 분봉(1분 가격 + 누적 거래량, 최근 약 7거래일)을 끝난 거래일만 `minute-data` 브랜치의 `minute/YYYY/MM/DD.json.gz`로 저장. 놓친 날은 다음 실행에서 채움
- 하루 약 440KB(100종목), 1년 약 110MB
- 몇 달 쌓이면 진입·익절·손절 규칙을 실제 장중 경로로 검증할 예정 (일봉은 고가·저가의 순서를 몰라 익절·손절을 정확히 시험할 수 없음)
- 장중에 수집기를 돌리면 오늘의 미완성 일봉은 제외하고 '어제까지'로 계산

## 한계

- 하루 방향은 대부분 잡음입니다. 첫 수집 기준 100개 종목 중 p < 0.05인 종목은 8개로, 우연만으로도 5개 정도는 나옵니다.
- 대상은 시가총액 상위 100개뿐입니다(`UNIVERSE_KOSPI`, `UNIVERSE_KOSDAQ`로 조정).
- 네이버·Yahoo 엔드포인트는 비공식입니다.

## 2차 실험 결과 (2026-11, 보정 후 125거래일 × 100종목)

| 설정 | 시가 적중 | 시가 확률 점수 | 종가 적중 | 종가 확률 점수 | 기본 대비 t (종가) |
|---|---|---|---|---|---|
| 1차 (7, 자르기 없음) | 63.7% | +9.2% | 55.7% | +1.6% | −0.7 |
| **기본 (7, 5σ)** | 63.6% | +9.2% | 55.7% | +1.7% | 기준 |
| 확장 (14, 5σ) | 63.3% | +9.6% | 55.6% | +2.1% | +0.8 |
| 패널 (14, 5σ, 수축 0.2) | 63.6% | +9.5% | 55.9% | +2.0% | +0.6 |

- 가장 큰 개선은 **예측 대상을 시가 갭과 종가로 나눈 것**과 **확률 보정**입니다(보정 전 종가 확률 점수 +0.1% → +1.7%).
- EWY, VIX, 금리, 달러, 5일 수급은 나스닥·반도체 지수가 이미 담은 정보와 겹쳐 의미 있는 추가 효과가 없었습니다.
- 패널 모델은 종목별 수축을 강하게(1.0) 하면 오히려 나빠졌고, 0.2에서 기본과 비슷했습니다.
