# 구조와 설계

## 왜 정적 사이트 + 정기 수집인가

| 원본 (Express 서버) | 지금 (정적 + GitHub Actions) |
|---|---|
| 방문자마다 Yahoo·네이버·Gemini를 실시간 호출 → 한도 초과, 느림, 차단 위험 | 하루 두 번 한 곳에서만 수집. 방문자는 JSON 파일만 받음 |
| 서버 호스팅 필요 (Cloud Run 등) | GitHub Pages 무료, 서버 없음 |
| API 키가 서버에 상주 | 키는 Actions 비밀값으로만 사용, 사이트에는 없음 |
| 과거 데이터가 없어 백테스트를 난수로 꾸밈 | 2년치 실제 데이터로 학습·검증 |

국내 시세는 장 마감 후에만 확정되고, 이 모델의 입력(미국 장 마감, 전일 수급)은 하루에 한 번 바뀌므로 "실시간" 호출은 얻는 것이 없습니다.

## 파일

```
shared/                 수집기와 화면이 함께 쓰는 코드
  types.ts              JSON 형식
  stats.ts              정규분포, 릿지 회귀, 상관계수
  model.ts              입력 만들기, 학습, 예측, 워크포워드 백테스트, 프리셋
scripts/
  collect.ts            수집 → 학습 → 백테스트 → public/data/
  http.ts               타임아웃·재시도·호출 간격(120ms)
  sources/naver.ts      시가총액 순위, 일봉, 투자자별 매매, 뉴스
  sources/yahoo.ts      해외 지표 일봉
  sources/gemini.ts     (선택) 시장 배경 해설
src/                    React 화면 (정적 JSON만 읽음)
tests/                  모델 테스트 (가짜 시장 데이터로 검증)
.github/workflows/      update.yml(수집·배포), ci.yml(PR 검사)
```

## 데이터 파일

- `data/index.json`: 갱신 시각, 지수·해외 지표, 100개 종목 요약(종가, 상승 확률, 백테스트 적중률), 시장 요약
- `data/stocks/{코드}.json`: 최근 120거래일 원자료, 학습된 모델 계수, 다음 거래일 입력값과 기준 날짜, 예측, 백테스트 60일, 뉴스 3건

전체 약 2MB. 종목 파일은 선택할 때만 받습니다.

## 모델

한국 거래일 t의 수익률 yₜ(%)를, t일 장이 열리기 **전에** 알 수 있는 값으로 설명합니다.

| 입력 | 정의 |
|---|---|
| 나스닥, 필라델피아 반도체 | t보다 앞선 마지막 미국 거래일의 등락률 |
| 원/달러, WTI | t보다 앞선 마지막 일봉의 변화율 |
| 외국인·기관 순매수 | t−1일 순매수 수량 ÷ (t−20…t−1) 평균 거래량 × 100 |
| 전 거래일 수익률 | t−1일 등락률 |

- 학습: 입력을 표준화한 뒤 릿지 회귀(λ = 0.1 × 학습 일수), 종목별 최근 250거래일
- 예측: 기대 수익률 μ = 절편 + Σ 계수 × 입력, 상승 확률 = Φ(μ / 잔차 표준편차)
- 요인 기여: 계수 × (입력 − 학습 기간 평균) → "평균적인 날보다 얼마나 올렸나/내렸나"
- 가격제한폭(30%)을 넘는 변동(액면분할 등)이 있는 날은 학습에서 제외
- 입력이 학습 기간 평균에서 표준편차 3배 넘게 벗어나면 화면에 경고 (선형 모델의 과장 위험)

## 백테스트

최근 60개 표본 각각에 대해, 그 날 **이전** 250개 표본만으로 모델을 새로 학습해 예측합니다(워크포워드). 테스트로 미래 정보 누출이 없음을 확인합니다.

- 적중률(보합일 제외)과 '매일 상승이라고만 했을 때' 적중률 비교
- p값: 적중률이 50%와 다른지 정규 근사 양측 검정
- 예측-실제 상관, 상승 전망일만 보유 vs 계속 보유 수익률(비용·세금 제외)

## 원본에서 고친 문제

| 원본 | 지금 |
|---|---|
| 백테스트 예측이 난수(72% '적중' 고정) | 워크포워드 실제 검증 |
| 사람이 정한 가중치를 "머신러닝"으로 표기 | 실제 데이터로 학습, 계수 공개 |
| 환율·유가 부호가 이중으로 뒤집혀 의도와 반대로 계산 | 회귀가 방향을 데이터에서 추정 |
| 확률 = 35 + 60·sigmoid (점수 0에서 '상승 65%') | Φ(μ/σ), 0이면 50% |
| 외국인 수급을 AI 검색·추정치로 채움 | 네이버 투자자별 매매 실측값 |
| 뉴스 실패 시 가짜 헤드라인 | 없으면 "없음" |
| 종목 목록이 서버 전역 변수(모든 사용자 공유) | 관심 종목은 각자 브라우저에 |
| 날짜 하드코딩(2026-05-30) | 실제 날짜 |
| 확대 금지, 버튼 11.5px | 확대 허용, 본문 14px+, 터치 44px+ |

## 한계

- 하루 방향은 대부분 잡음입니다. 첫 수집 기준 100개 종목 중 p < 0.05인 종목은 8개로, 우연만으로도 5개 정도는 나옵니다.
- 대상은 시가총액 상위 100개뿐입니다(`UNIVERSE_KOSPI`, `UNIVERSE_KOSDAQ`로 조정).
- 네이버·Yahoo 엔드포인트는 비공식입니다.
